## 1. Project Description

This project is part of my Week 1 MySQL Database assignment. The purpose of this assignment is to practise creating and managing databases using MySQL.

I chose the Hospital Management System because it helps organize basic hospital information, including patients, doctors, and appointments.

## 2. Database Tables

The database contains three tables:

### Patients
Stores patient information:
- Patient ID
- First Name
- Last Name
- Gender
- Age
- Phone
- Address

### Doctors
Stores doctor information:
- Doctor ID
- First Name
- Last Name
- Specialization
- Phone

### Appointments
Stores appointment information:
- Appointment ID
- Patient ID
- Doctor ID
- Appointment Date
- Reason

## 3. SQL Commands Used

The following MySQL commands were used in this project:

- `CREATE DATABASE` – Creates a new database.
- `SHOW DATABASES` – Displays available databases.
- `USE` – Selects a database.
- `CREATE TABLE` – Creates database tables.
- `SHOW TABLES` – Displays tables in a database.
- `DESCRIBE` – Displays the structure of a table.
- `PRIMARY KEY` – Uniquely identifies each record.
- `FOREIGN KEY` – Connects related tables.
